# Shinobi Viewer

Экспериментальный Android-клиент Shinobi: вход, сетка, просмотр основного и дополнительного потока, архив. Пароль и токен не сохраняются; при закрытии приложения потребуется повторный вход.

## Сборка

Нужны JDK 17, Android SDK Platform 36 и Build Tools 35.0.0. Задайте `ANDROID_HOME` и выполните `./gradlew assembleDebug`. APK появится в `app/build/outputs/apk/debug/`. Debug-подпись предназначена только для тестов. Используемый AGP 8.7.3 официально рекомендует SDK не выше 35; предупреждение для пробной сборки подавлено.

## Потоки

Клиент использует LibVLC 3.7.7, получает настройки через API Shinobi и регистрирует открытые мониторы через Socket.IO. Поле `toggleSubstream` в Shinobi — общесерверный переключатель, поэтому клиент сначала проверяет статус и не выключает уже работающий дополнительный поток самостоятельно. Между проверкой и переключением возможна гонка с другим клиентом; перед постоянным использованием необходимо проверить поведение при одновременной работе браузера и приложения. Уличные камеры используют канал 102 для обычного качества, внутренние — наоборот; приложение определяет соотношение по настройкам монитора.

HTTP разрешён для подключения к локальному серверу, для внешнего подключения используйте HTTPS. Исходный пароль и API-токен в файл не записываются; системное резервное копирование приложения отключено.

В проекте не копировался код Cams. Используется LibVLC; условия распространения бинарной сборки и её компонентов следует отдельно проверить до публикации.

## Проверки

Для проверки на устройстве нужны вход в Shinobi, работа обоих качеств на уличной и внутренней камере, одновременный просмотр с веб-интерфейсом и воспроизведение архива. Эти проверки должны выполняться с реальным сервером и телефоном.
