# Камеры дома №9 · Shinobi Android

Android-клиент домашнего Shinobi. Адрес сервера по умолчанию — `https://cam.lex42.ru`. Список камер загружается с сервера в соответствии с правами аккаунта.

## Возможности

- Камеры: лента, перестановка долгим нажатием, полноэкранный просмотр двойным нажатием, SD/4К, масштабирование двумя пальцами, снимок и архив выбранной камеры.
- Записи: несколько камер на общей временной шкале, выбор даты/времени, скорость воспроизведения и отображение пропусков записей.
- Скачать или отправить запись в SD либо исходном качестве. Отсутствующий SD у старой записи явно обозначается.
- Светлая, тёмная и системная темы. Необязательное запоминание пароля с шифрованием Android Keystore. При выходе сохранённые данные удаляются.

Сервер должен поддерживать авторизацию Shinobi, Socket.IO WebSocket, основной/дополнительный поток и API `?variants=1` для вариантов архива. Внешнее подключение рекомендуется через HTTPS; HTTP оставлен для локальной сети. Приложение не вводит ограничений 4К на мобильном интернете.

## Сборка

JDK 17, Android SDK Platform 36, Build Tools 35.0.0, Gradle 8.9 / AGP 8.7.3:

```sh
gradle --no-daemon assembleRelease
```

Release APK требует подписи. Локальные расположения инструментария и ключа описаны в AGENTS.md; секретные файлы не входят в репозиторий. Debug-подпись предназначена только для тестирования.

## Проверки

В `tests/` находятся проверки разрешённых камер, URL вариантов архива, временных интервалов и безопасности экспорта. Android-тесты проверяют функции, которым требуется устройство. Фактическое воспроизведение камеры зависит от декодера телефона и сети; успешная сборка не заменяет проверку на целевом телефоне.

Live использует LibVLC, архив — системный Android-плеер. Ранее аппаратный LibVLC некорректно отображал HEVC на целевом телефоне, поэтому архив отделён от live-плеера. Для подключения нужен Socket.IO transport `websocket`.
